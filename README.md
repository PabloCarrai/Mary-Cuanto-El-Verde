#	Mary-Cuanto-El-Verde
<br>
La idea basica es una app en python que me averigue la cotizacion del dolar y me informe del mismo a traves de mensajes en telegram. 

```
git clone https://github.com/PabloCarrai/Mary-Cuanto-El-Verde.git
cd Mary-Cuanto-El-Verde/

El archivo .env-Ejemplo tiene dos elementos que necesito completar 
TOKEN="Aca va tu token del bot"
ID="Aca el id del chat"
Una vez que pongo los datos propios renombro el archivo como .env

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3.13 app.py
```
